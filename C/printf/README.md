# Description
The project has for goal to recode the `printf()` function from libc.

# Instructions  
Run the Makefile
> make

This compiles all sources files and generates `libftprintf.a`

To use a function from the library
> cc your_program.c libftprintf.a -o your_program

### ft_putchar("0123456789ABCDEF"[n % 16])

`n % 16` gives the remainder of `n` divided by 16, which corresponds to the value of the current hexadecimal digit.
